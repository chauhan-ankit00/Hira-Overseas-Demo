
# Hira Overseas

Hira Overseas manpower consultancy landing page built with React, TypeScript, and Vite.

## Setup

1. Install dependencies:

   ```sh
   npm install
   ```

2. Copy `.env.example` to `.env` and set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` for your Supabase project.

3. Start the development server:

   ```sh
   npm run dev
   ```

Create a production build with `npm run build`.
